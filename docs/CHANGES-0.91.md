## Отдельно от этих 21 пункта

- Три режима активности расчётов: видимая вкладка, фокус на сайте, фон с ограничениями браузера. При паузе останавливаются планировщик и CFD worker. Накопление времени при возвращении сбрасывается.
- Быстрое переключение четырёх тонов кнопками; компактнее настройки, уточнён контраст карточек и диагностики.
- Срединный шаг прогноза аккумулятора: ток и сопротивление пересчитываются на промежуточном состоянии. Остановка на резерве уточняется по заряду.
- CFD: одинаковые физические границы на трёх сетках, режим одинаковой базовой численной вязкости, таблица сил по сеткам.
- CFD: диагностика продолжения привязана к абсолютным итерациям; неподходящее сохранённое состояние отклоняется; финальный признак установления проверяет итоговый баланс массы и плотности.

Сравнение сеток не выдаётся за доказанную сеточную независимость. Разница между двумя результатами не называется погрешностью. Стендовая проверка реального дрона не проводилась.
