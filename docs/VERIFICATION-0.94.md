# Проверка 0.94 Beta

Дата сборки: 2026-11-21. Исходная версия: 0.93.1 Beta. Среда: Node 22.23, Linux, Chromium (Playwright).

Все проверки запускаются одной командой: `node scripts/verify-all.mjs`. Она прогоняет 15 проверок: `verify`, `verify-v06` … `verify-v094`, `verify-ui` и `verify-standalone`. Все завершились с кодом 0. Протоколы лежат в `verification-logs/v094-run-*.log`. Те же проверки запускает GitHub при каждом изменении в main (`.github/workflows/tests.yml`).

## Новая проверка `verify-v094.mjs`

Числа лежат в `../verification-v094.json`.

1. **Стендовые таблицы T-MOTOR MN4014 (15 × 5, 22,2 В).**
   - KV330: тяга 2,9%, мощность 7,5%.
   - KV400: тяга 5,8%, мощность 1,9%.
   - Подбор по таблицам даёт FM 0,70 и 0,73, R² тяги больше 0,99.
2. **Винт по умолчанию.**
   - FM 0,67. Формула 0.93 давала 0,26.
   - Висение 10,5 г/Вт.
3. **Мотор по даташиту.**
   - Мощность на входе равна сумме мощности на валу и потерь в меди и железе.
   - При 125 °C сопротивление обмотки ×1,393, и для того же момента нужен больший ток.
   - У КПД есть максимум внутри диапазона оборотов.
   - Полный газ на 22,2 В: KV330 5 902 об/мин (в таблице 6 000), KV400 7 003 (в таблице 6 700).
4. **Предел по напряжению.** При 15% заряда предел оборотов ниже, на 8S выше. Стандартный дрон с мотором по даташиту висит.
5. **Нагрев.**
   - Исправный мотор на стенде при 7 200 об/мин не горит: простая модель 81 °C, модель по даташиту 51 °C.
   - В полёте мотор нагревается до 19 °C.
   - Все три опыта с перегрузкой идут по порядку дым, огонь, отказ, а батарея не отключается раньше.
6. **Прогноз.** Время до дыма по формуле 52,73 с, по пошаговому расчёту 52,74 с.
7. **Отказ мотора.** Гексакоптер без одного мотора держит подъёмную силу и рысканье. Рабочие моторы несут в 1,5 раза больше.
8. **Загрузка CSV.**
   - Граммы, кгс и ньютоны читаются правильно, десятичная запятая тоже.
   - Подбор находит заданные Ct и Cp точно.
   - Журнал 60 с при 24 В и 10 А даёт 240 Вт, 4 Вт·ч и 166,7 мА·ч.
9. **Пресеты и старые проекты.**
   - У всех пресетов от 144 до 171 Вт·ч на килограмм батареи, и все висят.
   - Проект без новых полей считается как с простой моделью мотора.
