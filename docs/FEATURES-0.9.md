## Ограничения

CFD-ядро сохранено из 0.89. Новые панели делают работу с результатом удобнее, но не добавляют экспериментальной достоверности. Косметические детали 3D и разнесение корпуса не меняют физическую геометрию CFD.

План полёта использует постоянную нагрузку на горизонтальных участках и встречный ветер. Он не считает разгон, энергию набора высоты, маршрутный курс и износ моторов по ходу маршрута. Расчёт собственного дрона использует начальный заряд и исправные моторы.

Масса батареи в редакторе равна сумме масс ячеек. Корпус, провода и крепления добавляй как компоненты. Четыре кривые напряжения и тепловые коэффициенты примерные, не паспортные данные производителей. Моменты инерции считаются по точечным массам, а не по объёмной геометрии деталей.

Проекты и профили сохраняются в браузере только по нажатию кнопки. Экспортируй JSON для резервной копии. Журнал полёта существует в текущей вкладке.
