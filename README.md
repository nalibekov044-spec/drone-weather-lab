# Drone Weather Lab

Версия 0.5.0 — предварительный инженерный симулятор прямо в браузере.

Интерактивный браузерный симулятор мультикоптера. Проект показывает, как ветер, порывы, вертикальные потоки, дождь, обледенение, плотность воздуха, масса, геометрия винтов, RPM и ограничения силовой установки влияют на устойчивость и время полёта.

## Возможности

- интерактивная 3D-сцена полёта с удержанием позиции;
- четыре конфигурации дрона: FPV, камерный квадрокоптер, промышленный гексакоптер и грузовой октокоптер;
- индивидуальная настройка RPM каждого двигателя;
- расчёт тяги и мощности через безразмерные коэффициенты `Ct` и `Cp`;
- ограничения по мощности, максимальным RPM и углу наклона;
- тепловая модель моторов: перегрев, потеря ресурса, снижение тяги, дым и возгорание;
- графики зависимости результатов от параметров;
- трёхмерный CFD-режим D3Q19 Lattice Boltzmann;
- отображение скорости, давления и завихрения потока;
- дополнительные объекты в CFD-области.
- импорт STL / OBJ из CAD: размер, ось вверх, поворот, проверка замкнутости;
- замкнутая импортированная сетка может заменить корпус в CFD;
- до 360 линий в Web Worker, плавные частицы по локальной скорости;
- кубические ячейки, источник импульса дисков, связанный с вертикальной тягой;
- невязка, размер ячейки, дивергенция, физический и численный Re;
- измеренные Cₜ/Cₚ, просадка батареи, C-рейтинг, Мах конца лопасти;
- экономный / авто режим, кеширование сцены и остановка скрытой вкладки;
- пояснения параметров, инженерные показатели и экспорт JSON-отчёта.

## Перенос из CAD

Экспортируй корпус и раму без вращающихся винтов в STL (ASCII / binary) или треугольный OBJ. Ограничения: 16 МБ, 40 000 треугольников. Файл обрабатывается локально, не отправляется на сервер. Укажи наибольший реальный размер в мм и ось вверх. Масса, параметры моторов и C𝒹 вводятся отдельно.

Для CFD нужна замкнутая сетка; проверка рёбер не гарантирует отсутствие самопересечений. Перекрывающиеся тела лучше объединить в CAD. STEP / IGES напрямую не поддерживаются. Центры дисков задаёт типовая рама: проверь их совпадение с корпусом. Тонкие детали могут исчезнуть на воксельной сетке. Для больших файлов предпросмотр упрощён кластеризацией вершин, но вокселизация использует все треугольники.

## Запуск

Модульный Web Worker требует локальный HTTP-сервер. Из корня проекта:

```bash
python -m http.server 8000 --directory dist
```

Затем откройте `http://localhost:8000`.

В Windows вместо `python` можно использовать:

```powershell
py -m http.server 8000 --directory dist
```

## Публикация через GitHub Pages

В проект уже добавлен workflow `.github/workflows/pages.yml`. После загрузки репозитория на GitHub откройте **Settings → Pages**, выберите **GitHub Actions** в качестве источника и отправьте изменения в ветку `main`. Содержимое `dist` будет опубликовано автоматически.

## Структура

- `dist/index.html` — интерфейс симулятора;
- `dist/app.js` — управление состоянием, полёт и тепловая модель;
- `dist/physics.js` — атмосфера, тяга, мощность и ограничения;
- `dist/systems.js` — тепловое состояние и повреждение моторов;
- `dist/scene3d.js` — интерактивная 3D-визуализация;
- `dist/cfd-core.js` — численный D3Q19 LBM-решатель;
- `dist/cfd-worker.js` — фоновый запуск CFD;
- `dist/flow-lines.js` — интерполяция и интегрирование 3D-линий;
- `dist/mesh-import.js` — STL / OBJ, топология, вокселизация;
- `dist/mesh-worker.js` — фоновая обработка CAD;
- `dist/renderers.js` — графики;
- `dist/styles.css` — оформление и адаптивная вёрстка.

## Точность

CFD — стабилизированный BGK D3Q19 LBM на кубических ячейках. Сила дисков нормирована к вертикальной тяге и вводится схемой Guo. Источник действует около плоскости винта, не искусственно вдоль всей струи. Сетка: 13 175 / 31 119 / 60 639 ячеек; максимум 100 / 220 / 360 итераций. Остановка возможна при относительном изменении поля менее 0,1% между отсчётами через 20 итераций. Это не доказательство точности.

Численная вязкость повышена: Re решателя существенно ниже физического Re. Модель предназначена для предварительного сравнения тенденций, это не промышленный CFD. Пограничный слой, реальные лопасти, развитая турбулентность и точный отрыв не разрешаются. CFD показывает средний ветер; порывы относятся к динамике полёта. Сеточная сходимость и экспериментальная валидация не выполнены. Давление — избыток относительно входа, не абсолютное атмосферное.

Коэффициенты винтов требуют стендовой проверки. Возгорание моторов — условный стресс-тест, не прогноз пожарной опасности. Батарея использует постоянное сопротивление и номинальную энергию, не полную электрохимическую модель. Отчёт не подтверждает безопасность реального полёта.

Основы: [теория диска — NASA](https://www.grc.nasa.gov/www/k-12/airplane/propth.html), [сопротивление — NASA](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/drag-equation/), [Guo et al., 2002](https://doi.org/10.1103/PhysRevE.65.046308).

## Проверка

```bash
node --experimental-vm-modules scripts/verify.mjs
node --experimental-vm-modules scripts/verify-ui.mjs
```

Проверяет физические зависимости, отказ мотора, батарею, топологию / вокселизацию, конечность CFD, кубический шаг и линии тока. Не заменяет визуальную проверку и валидацию CFD.
