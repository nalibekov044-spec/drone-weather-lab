# Drone Weather Lab 0.89 Beta

[English](README.en.md)

Симулятор показывает, как ветер, высота, винты и батарея влияют на мультикоптер. Версия 0.89 небольшая. В ней новые горячие клавиши и исправления в модели батареи, графиках и CAD.

## Запуск

Распакуй ZIP и открой **Drone-Weather-Lab-0.89-Beta.html**. Устанавливать ничего не нужно, интернет тоже. Стили, код и расчётные модули уже встроены в этот файл.

Бывает, что браузер не запускает расчёты из локального файла. Тогда открой проект через небольшой сервер: `python scripts/start.py`. На Windows то же самое делает `Start.cmd`.

Папка `dist/` готова для публикации как сайт. Если в репозитории включить GitHub Pages, сайт будет собираться сам после каждой отправки в `main`. Готового EXE в архиве нет, но скрипты для его сборки сохранены.

## Что нового

- **Горячие клавиши.** Клавишами можно переключать все четыре вида, менять батарею, скачивать отчёт и настройки, показывать силы, возвращать камеру и открывать справку. Работает физическое положение клавиши, поэтому русская раскладка не мешает. Пока ты печатаешь в поле, клавиши не срабатывают.
- **Баланс мощности.** Новая карточка показывает, куда уходит энергия батареи: на валы, моторы, ESC, электронику и RC-ветвь.

## Исправления

- Энергия и нагрев RC-ветви батареи считаются аналитически внутри каждого шага.
- Быстрая оценка времени полёта больше не уменьшает ёмкость на холоде дважды.
- Прогноз берёт ток и напряжение из конечного состояния. Если напряжение падает ниже порога контроллера, доступная тяга уменьшается.
- Сильный восходящий поток больше не получает искусственный минимум потребной тяги.
- Графики не выходят за свой диапазон. Они используют текущее состояние батареи и ESC.
- На паузе больше не остаются старые данные о мощности.
- CAD не пересчитывается, если модель не менялась. Смена пресета обновляет масштаб. Строки ASCII STL с ошибками отклоняются.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Пробел | Пауза или продолжение |
| 1, 2, 3, 4 | Полёт, графики, обтекание, сравнение |
| G, C | Графики и обтекание (прежние клавиши) |
| R | Начать полёт заново. Батарея и моторы сохраняются |
| Shift + R | Сбросить настройки, батарею, моторы и CAD |
| F | Восстановить моторы |
| B | Заменить аккумулятор |
| E | Скачать отчёт JSON |
| S | Скачать настройки JSON |
| V | Показать или скрыть силы |
| O | Вернуть камеру на место |
| H или ? | Открыть или закрыть справку |
| Esc | Закрыть справку |

Сочетания с Ctrl, Alt и Meta программа не перехватывает. Кнопки по-прежнему работают с клавиатуры как обычно.

## Ограничения

Это учебная модель. CFD работает на грубой сетке D3Q19, и вязкость в ней выше настоящей. Лопасти и пограничный слой не моделируются. Сила из CFD показывается отдельно и в движение дрона не передаётся. В 0.89 ядро CFD не менялось.

Батарея и моторы не сверялись с реальным оборудованием. Площадь CAD считается по силуэту. Массу, Cd и материал задаёшь сам. Масса батареи уже должна входить в массу дрона.

Описание функций CAD, CFD и питания из 0.88 лежит в `docs/FEATURES-0.88.md`. Для проверки размеров есть модель `examples/box-100x40x200-mm-Y-up.obj`.
