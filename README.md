# Drone Weather Lab

Интерактивный браузерный симулятор мультикоптера. Проект показывает, как ветер, порывы, вертикальные потоки, дождь, обледенение, плотность воздуха, масса, геометрия винтов, RPM и ограничения силовой установки влияют на устойчивость и время полёта.

## Возможности

- интерактивная 3D-сцена полёта с удержанием позиции;
- четыре конфигурации дрона: FPV, камерный квадрокоптер, промышленный гексакоптер и грузовой октокоптер;
- индивидуальная настройка RPM каждого двигателя;
- расчёт тяги и мощности через безразмерные коэффициенты `Ct` и `Cp`;
- ограничения по мощности, максимальным RPM и углу наклона;
- тепловая модель моторов: перегрев, потеря ресурса, снижение тяги, дым и возгорание;
- графики зависимости результатов от параметров;
- трёхмерный CFD-режим D3Q19 Lattice Boltzmann;
- отображение скорости, давления и завихрения потока;
- дополнительные объекты в CFD-области.

## Запуск

Модульный Web Worker требует локальный HTTP-сервер. Из корня проекта:

```bash
python -m http.server 8000 --directory dist
```

Затем откройте `http://localhost:8000`.

В Windows вместо `python` можно использовать:

```powershell
py -m http.server 8000 --directory dist
```

## Публикация через GitHub Pages

В проект уже добавлен workflow `.github/workflows/pages.yml`. После загрузки репозитория на GitHub откройте **Settings → Pages**, выберите **GitHub Actions** в качестве источника и отправьте изменения в ветку `main`. Содержимое `dist` будет опубликовано автоматически.

## Структура

- `dist/index.html` — интерфейс симулятора;
- `dist/app.js` — управление состоянием, полёт и тепловая модель;
- `dist/physics.js` — атмосфера, тяга, мощность и ограничения;
- `dist/systems.js` — тепловое состояние и повреждение моторов;
- `dist/scene3d.js` — интерактивная 3D-визуализация;
- `dist/cfd-core.js` — численный D3Q19 LBM-решатель;
- `dist/cfd-worker.js` — фоновый запуск CFD;
- `dist/renderers.js` — графики;
- `dist/styles.css` — оформление и адаптивная вёрстка.

## Точность

CFD-режим использует ограниченную сетку ради работы прямо в браузере. Для проектирования реального аппарата коэффициенты конкретных винтов и двигателей необходимо сверять со стендовыми испытаниями, а геометрию — с расчётами высокой точности.
