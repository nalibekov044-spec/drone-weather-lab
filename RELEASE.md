# Drone Weather Lab 0.95 Beta

Третий редизайн. Сцена и главные цифры видны сразу, верх страницы занимает в два раза меньше места. По умолчанию показаны только главные параметры.

Погода по месту: Алматы, Шымбулак, БАО, Медеу, Астана или свои координаты. Батарея пересчитана: исправлена LiFePO4, масса следует за ёмкостью, а новый график показывает, какая батарея даёт больше времени. Гоночный дрон получил трёхлопастной винт по стендовой таблице. Свой CAD теперь можно загрузить в 3MF, до 64 МБ, просто перетащив на сцену.

Скачай ZIP, распакуй и открой Drone-Weather-Lab-0.95-Beta.html. Модель сверена со стендом, но не с полётом реального дрона.
