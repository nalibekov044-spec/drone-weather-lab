# Drone Weather Lab 0.88 Beta

Based on the 0.87 Beta attached source archive.

- Integer battery series count, coupled ESC/bus power limits and reserve/cutoff endurance forecast.
- Relative-airflow drag, improved humidity handling, mass-flow/density CFD convergence gates and rotor/mesh domain checks.
- CAD source units, independent dimensions, aspect lock, continuous yaw, concave OBJ triangulation and optional projected silhouette area.

Download the project ZIP, extract it, then open Drone-Weather-Lab-0.88-Beta.html. dist/ contains the static website files. Numerical verification results are included. This is an educational model with no experimental drone validation. Windows EXE is not included in this package.
